# First milestones

## 0 — Ownership scaffold

Establish the public repository, directory responsibilities, MIT license, and contribution rules.
This milestone does not ship components, installers, or a runnable application.

## 1 — One complete Web slice

Implement one style with light/dark appearance, a small semantic token schema, and a settings
pattern composed from reusable controls. Add a runnable example and validate keyboard/focus,
responsive behavior, appearance, and reduced motion. Pick dependencies and commit the lockfile.

## 2 — Distribution and website integration

Publish validated Web registry artifacts and matching examples from the same source revision.
Document installation into a clean consumer. Connect fast-ui-site to a pinned version.
Add AI-readable usage, dependencies, constraints, and integration instructions.

## 3 — Prove cross-platform design

Implement the same settings interaction in one mobile and one desktop example. Document
intentional differences and verify on named devices/platforms before claiming support.
Extract token export tooling only after the implementations demonstrate its requirements.

## 4 — Grow from usage

Expand themes and patterns based on real consumer needs. Add release automation and compatibility
policy as packages become publishable. Separate repositories only for independent ownership or
release requirements, not simply because another platform exists.
